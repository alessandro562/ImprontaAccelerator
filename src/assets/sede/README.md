# Foto della sede

Metti qui la foto di Villa Fassini e la sezione «La sede e la community» smette
di mostrare il segnaposto. Non serve toccare il codice.

| File atteso | |
|---|---|
| `villa-fassini.jpg` | anche `.png` o `.webp` |

- Formato orizzontale o quadrato: in pagina viene ritagliata in **4:3**.
- Almeno 1600px di lato lungo, per gli schermi densi.
- Finché il file manca resta un riquadro tratteggiato che dichiara che la foto
  va inserita: così non si pubblica per sbaglio un vuoto silenzioso.
